# Worky — статичний фронтенд архітектурної студії

Навчальний проєкт із дисципліни «Web-технології». Статична білінгвальна версія сайту архітектурної студії **Worky** — без Django, без бази даних, без збірки. Відкривається локально подвійним кліком по `index.html`.

## Мета проєкту

Переробити оригінальний Django-проєкт [vladkolyada/web_project](https://github.com/vladkolyada/web_project) у повністю адаптивний статичний сайт, який демонструє:
- семантичний HTML5;
- CSS Grid для двовимірних розкладок;
- CSS Flexbox для одновимірних компонентів;
- медіазапити та container queries;
- mobile-first підхід;
- перемикання UA/EN без бібліотек.

## Три основні сторінки

| Сторінка | Призначення | Ключові техніки |
|---|---|---|
| `index.html` | Презентація студії: hero, напрями, галерея натхнення | Grid `auto-fit`, `clamp()`, hero з паралакс-анімацією |
| `services.html` | Шість напрямів і три пакети послуг | Container queries, `cqi`, Grid для пакетів |
| `blog.html` | Список статей + пошук | Flexbox, `container: post / inline-size`, пошук на JS |

Усі три мають різний вміст і різні макети, а не лише різні заголовки.
